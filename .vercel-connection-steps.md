# Vercel Connection Steps

## Step 1: Login to Vercel

Run this command in your terminal:
```bash
vercel login
```

This will:
1. Open your browser to authenticate
2. Or show a device code to enter at https://vercel.com/login

## Step 2: Link Your Project

After logging in, run:
```bash
vercel link
```

You'll be prompted to:
- **Link to existing project?** → Choose if you already have a Vercel project
- **Create new project?** → Choose if this is a new deployment
- **Project name:** → `interpwhat` (or your preferred name)
- **Directory:** → `.` (current directory)

## Step 3: Configure Environment Variables

After linking, you need to set environment variables in Vercel:

### Option A: Via Vercel Dashboard (Recommended)
1. Go to https://vercel.com/dashboard
2. Select your `interpwhat` project
3. Go to **Settings** → **Environment Variables**
4. Add all required variables (see `docs/VERCEL-DEPLOYMENT.md`)

### Option B: Via CLI
```bash
vercel env add DATABASE_URL production
vercel env add OPENAI_API_KEY production
# ... add all other variables
```

## Step 4: Deploy

Once linked and variables are set:

```bash
vercel --prod
```

This will:
- Build your project
- Deploy to production
- Give you a deployment URL

## Alternative: Connect via GitHub (Easier)

If you prefer, you can skip the CLI and:
1. Go to https://vercel.com/dashboard
2. Click **Add New...** → **Project**
3. Import your GitHub repository: `zganich/interpwhat`
4. Vercel will auto-detect settings
5. Add environment variables in the dashboard
6. Click **Deploy**

This method is often easier and sets up automatic deployments from GitHub!
